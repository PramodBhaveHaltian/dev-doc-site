Haltian EH Locator

Light-powered IoT anchor device for Wirepas mesh networks. Operates as router or beacon for reliable asset tracking and positioning with energy harvesting capabilities.

Overview

The Haltian EH Locator is a versatile fixed network element designed for the Haltian Inventory Tracking Solution (HITS). This innovative device can harvest power from indoor lighting or sunlight, eliminating the need for constant external power and enabling flexible installation anywhere indoors.

The EH Locator serves as a critical component in Wirepas mesh networks, providing:

  • Dual operating modes: Router mode (for mesh networking) or Beacon mode (for positioning)
  • Energy harvesting: Powered by indoor light, sunlight, or USB-C
  • Extended battery life: Up to 10 days in router mode, 4 years in beacon mode
  • Reliable communication: Receives and transmits messages from asset tags and other routers
  • Positioning support: Transmits beacon messages for tag inventorying and positioning
Product Name

The EH Locator is sometimes referred to as “Solifer” in internal documentation and firmware files.

Key Features

Energy Harvesting

  • Solar panel: Integrated photovoltaic panel for indoor light and sunlight harvesting
  • USB-C powered: 5V USB-C input for continuous power (supports PoE-USB-C adapters)
  • Internal battery: 1,850 mAh Li-ion battery for backup power during outages
  • Power management: Intelligent system minimizes consumption for minimal maintenance

Dual Operating Modes

Router Mode

In router mode, the EH Locator:

  • Receives and transmits messages from asset tags and other routers
  • Transmits beacon messages every second (configurable) for positioning
  • Requires USB-C or sufficient light harvesting for continuous operation
  • Can operate up to 10 days on battery alone during power cuts
  • Status LED: Green (network)

Beacon Mode

In beacon mode, the EH Locator:

  • Does not route tag messages to other devices
  • Transmits beacon messages for tag positioning accuracy
  • Operates on minimal power consumption
  • Can operate up to 4 years on battery alone
  • Status LED: Blue (network)

Installation Flexibility

  • Multiple mounting options: indoor light mount, cable shelf mount, or wall mount
  • Sticky tape or zip tie mounting included
  • Compact form factor: 142.4 mm × 90.4 mm × 12.4 mm
  • Lightweight: 138g (158g with mounting bracket)

Power Management

Indoor Light Brightness Requirements

The EH Locator’s energy harvesting efficiency depends on indoor light brightness. For router mode operation without USB-C power, minimum light exposure hours per week are required:

Lux LevelRouter: Min On-Time per Week
40,000 lux35 hours
35,000 lux45 hours
30,000 lux50 hours
25,000 lux65 hours
20,000 lux85 hours
15,000 lux168 hours (always on)
10,000 luxUse USB-C power
Light Measurement

Measure lux levels at the height where the EH Locator will be installed to ensure adequate power harvesting.

For beacon mode, the device can operate up to 4 years on a fully charged battery, and even at low indoor light brightness (10,000 lux), the energy harvesting system can recharge the battery.

LED Status Indicators

The EH Locator features two LEDs for status indication:

Power LED (Green)

  • Off: No power / device switched off
  • Constant Green: USB-C power connected OR solar harvesting producing sufficient power

Network LED (Red/Green/Blue)

  • Blinking Green: Establishing mesh network or device just powered on
  • Constant Green: Mesh network established, operating in Router mode
  • Constant Blue: Operating in Beacon mode
  • Blinking Red: Error (network error, low battery, or undefined error)
LED Auto-Off

When operating correctly (state 6 or 7), the LEDs are only lit for the first 10 minutes after installation, then turn off to conserve power.

Typical Use Cases

Inventory Tracking

  • Deploy multiple EH Locators to create a mesh network covering warehouse or facility
  • Tags report to nearest locators
  • Locators forward messages to gateway and cloud platform
  • Real-time asset location tracking and inventory management

Indoor Positioning

  • Install EH Locators at regular intervals (recommended spacing: consult glossary for “Locator Spacing”)
  • Beacons provide RSSI-based positioning reference points
  • Tags calculate position based on signals from multiple locators
  • Accurate indoor asset positioning and zone detection

Mesh Network Extension

  • Add EH Locators to extend Wirepas mesh network coverage
  • Fill coverage gaps in challenging RF environments
  • Ensure reliable connectivity between tags and gateways

Configuration

EH Locators are configured and managed through Haltian IoT Studio:

  • Operating Mode: Switch between Router and Beacon modes
  • Beacon Interval: Adjust transmission frequency
  • Status Monitoring: View battery level, power source, network status
  • Firmware Updates: Remote firmware updates via cloud platform

See Haltian IoT Studio documentation for detailed configuration instructions.

Network Planning

For optimal performance:

  1. Locator Density: Deploy sufficient locators for area coverage
  2. Spacing: Follow recommended “Locator Spacing” guidelines (see Glossary)
  3. Mounting Height: Install at least 2.5m (7.5 feet) from floor for wall mounts
  4. Avoid Obstructions: Minimize metal surfaces blocking RF communication
  5. Power Planning: Ensure adequate lighting for energy harvesting in router mode

Getting Started

  1. Plan installation - Determine mounting location and method
  2. Install mounting bracket (if needed) - Use zip ties or sticky tape
  3. Power on device - Slide power switch to ON position
  4. Verify LEDs - Check Power LED (green) and Network LED
  5. Configure mode - Set Router or Beacon mode in Haltian IoT Studio
  6. Verify connectivity - Confirm device appears in IoT Studio
