Search

Search for devices using text, QR codes, or barcode scanners

For Viewers & Installers

Roles: Viewer, Installer, Designer, Manager

The Search feature is your primary tool for finding specific devices quickly.

Accessing Search

From the sidebar, tap Search under the Inventory section.

Search Methods

Text Search

  1. Tap the search text field
  2. Enter your search term:
    • Device name
    • Customer Label ID
    • Serial number
    • Wirepas Node ID
    • External ID
  3. Tap Search or press Return

The search will find devices matching your query across multiple identifier fields.

QR Code Scanning

  1. Tap Scan a QR code
  2. Point your camera at the device’s QR code
  3. The app will automatically search for the matching device

Tip: QR codes on Haltian devices contain structured data including device identifiers. See the QR Code Specification section for format details.

Bluetooth Barcode Reader

For high-volume scanning, you can connect an external Bluetooth barcode reader:

  1. Tap Bluetooth barcode reader to open iOS Settings
  2. Pair your barcode scanner
  3. Scanned codes will automatically populate the search field

Voice Feedback (Experimental)

When experimental features are enabled, you can toggle voice feedback:

  1. Tap the Speak/Don’t speak button
  2. When enabled, search results are announced out loud
  3. Helpful for hands-free operation during device installation

Search Results

  • Single match: Opens device detail view directly
  • Multiple matches: Displays a list of matching devices with device cards
  • No match: Shows “Can’t find any devices” alert

Tap any device in the results to view its details.

Search Tips

  • Use partial identifiers if you don’t know the complete ID
  • QR code scanning is faster than manual entry for installation workflows
  • External barcode scanners significantly speed up bulk device operations
  • Voice feedback is useful when your hands are occupied during installation
