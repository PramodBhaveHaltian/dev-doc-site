Configuration Log

View the history of device configuration changes

For Viewers & Installers

Roles: Viewer, Installer, Designer, Manager

View the history of device configuration changes.

Accessing Configuration Log

From the sidebar, tap Configuration log under the Devices section.

Log Information

The log shows a chronological list of all device configuration changes with:

  • Timestamp: When the configuration was changed
  • Device: Which device was configured (with device name/ID)
  • Change type: What was modified
  • User: Who made the change (username/email)
  • Details: Specific configuration values changed

Filtering the Log

By Date Range

  1. Tap the date filter
  2. Select Start date
  3. Select End date
  4. Apply filter

By Device

  1. Use the search field
  2. Enter device name or ID
  3. Log filters to show only that device’s changes

By Change Type

Filter by specific configuration types:

  • Position changes
  • Keyword assignments
  • Name changes
  • Configuration parameter updates
  • Installation/uninstallation events

Understanding Log Entries

Entry Structure

Each log entry typically includes:

[Timestamp]
Device: [Device Name/ID]
User: [User Name]
Action: [Configuration Change Type]
Details: [Specific values changed]

Common Change Types

Position Changes:

  • Device moved to new floor
  • Device repositioned on floor plan
  • Device installed/uninstalled

Property Changes:

  • Device name updated
  • External ID set
  • Keywords assigned or removed
  • Notes added or edited

Configuration Updates:

  • Reporting interval changed
  • Measurement thresholds modified
  • Device parameters adjusted

Use Cases

Audit Trail

  • Compliance: Verify who made changes and when
  • Accountability: Track user actions
  • History: Understand device configuration evolution

Troubleshooting

  • Identify recent changes: See if a configuration change caused an issue
  • Verify installations: Confirm devices were installed correctly
  • Track movement: See if a device was moved recently

Reporting

  • Activity reports: How many devices configured per day/week
  • User activity: Track team member contributions
  • Change frequency: Identify frequently modified devices

Exporting Log Data

Roles: Manager

To export configuration log data:

  1. Set desired date range and filters
  2. Navigate to Other > Export data in bulk
  3. Include configuration log data in export
  4. Download the export file

Best Practices

Regular Review

  • Periodically review the configuration log
  • Look for unexpected changes
  • Verify team members are following procedures
  • Identify devices with frequent configuration changes (may indicate problems)

Documentation

  • Add notes to devices when making significant configuration changes
  • Reference configuration log entries in incident reports
  • Keep configuration change records for compliance

Security

  • Review log for unauthorized changes
  • Monitor for unusual patterns
  • Ensure proper role-based access controls

Troubleshooting

Missing Log Entries

If expected changes don’t appear:

  • Verify the date range includes the change time
  • Check filters aren’t excluding the entry
  • Ensure the change was saved successfully
  • Some changes may appear with a delay

Understanding Historical Changes

For older entries:

  • Users may have changed roles or been removed
  • Devices may have been renamed
  • Configuration options may have changed over time
