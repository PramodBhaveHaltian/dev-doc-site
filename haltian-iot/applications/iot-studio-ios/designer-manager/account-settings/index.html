Account Settings

Manage your account, users, and organization settings

For Designers & Managers

Manage your personal account settings, user management, and organization administration.

Note: Organization Management and Data Retention sections are for Sysadmin only.

Own Settings

Roles: All users

Manage your personal account settings.

Accessing Account Settings

From the sidebar, tap Own settings under the Account section.

Account Information

View your:

  • Organization role: Your permission level (Viewer, Installer, Designer, Manager, Sysadmin)
  • Organization: Your organization name
  • Email: Your login email address
  • Identifier: Your user UUID

Changing Password

  1. Tap Change password
  2. Enter your current password
  3. Enter your new password
  4. Confirm the new password
  5. Tap Save

Password requirements:

  • Minimum length (typically 8 characters)
  • Mix of letters and numbers recommended
  • Case-sensitive

Logging Out

  1. Tap Log out
  2. You will be returned to the login screen
  3. Saved credentials are cleared

Tip: Log out when using a shared device for security.

User Management

Roles: Manager, Sysadmin

Manage users in your organization.

Accessing User Management

From the sidebar, tap Manage users under the Account section.

Viewing Users

  • List of all users in the organization
  • Each entry shows:
    • User name
    • Email address
    • Role
    • Active status
  • Use search to filter users

Adding Users

  1. Tap Add user or + button
  2. Enter user email address
  3. Select role from the dropdown:
    • Viewer
    • Installer
    • Designer
    • Manager
    • Sysadmin (Sysadmin only)
  4. Tap Send invitation

The user will receive an email invitation to create their account.

Editing Users

  1. Tap a user to view details
  2. Modify settings:
    • Role: Change user’s permission level
    • Status: Enable/disable account
  3. Save changes

Removing Users

  1. Swipe left on a user
  2. Tap Delete
  3. Confirm removal

Warning: Removing a user immediately revokes their access. This action cannot be undone.

Role Permissions

Understand what each role can do:

RoleKey Permissions
ViewerView devices and measurements only
InstallerInstall devices, assign keywords, edit properties
DesignerCreate spaces, floors, zones, floor plans
ManagerUser management, data export, full access
SysadminOrganization management, system settings

Organization Management

Roles: Sysadmin only

Manage organizations in the system.

Accessing Organization Management

From the sidebar, tap Edit organizations under the Account section.

Organization Operations

  • View all organizations: List of all organizations in the system
  • Create new organizations: Set up new tenant organizations
  • Edit organization settings: Modify organization properties
  • Delete organizations: Remove organizations and all their data

Warning: Organization management is a system-level function. Changes affect all users in the organization.

Creating an Organization

  1. Tap Add organization
  2. Enter organization name
  3. Configure settings
  4. Save

Editing an Organization

  1. Select an organization
  2. Modify settings
  3. Save changes

Deleting an Organization

  1. Select an organization
  2. Tap Delete
  3. Confirm deletion

Critical: Deleting an organization removes all sites, devices, users, and data permanently.

Data Retention Settings

Roles: Sysadmin only

Configure how long measurement data is retained.

Accessing Data Retention

From the sidebar, tap Data retention settings under the Account section.

Retention Configuration

Configure retention periods for:

  • Measurement data: How long sensor measurements are kept
  • Position history: How long location tracking data is retained
  • Configuration logs: How long configuration change history is kept

Setting Retention Periods

  1. Select data type
  2. Choose retention period:
    • 30 days
    • 90 days
    • 1 year
    • 2 years
    • Forever (not recommended for large datasets)
  3. Save settings

Data Cleanup

  • Data older than the retention period is automatically deleted
  • Deletion occurs during scheduled maintenance windows
  • Once deleted, data cannot be recovered

Best Practices

  • Compliance: Set retention periods according to regulatory requirements
  • Storage: Balance data retention with storage costs
  • Performance: Longer retention may slow queries on large datasets
  • Backups: Export important data before it expires

Switching Organizations

If you have access to multiple organizations:

  1. Go to Own settings
  2. Tap Organization
  3. Select from the list of organizations you belong to
  4. Tap Switch
  5. App reloads with new organization data
