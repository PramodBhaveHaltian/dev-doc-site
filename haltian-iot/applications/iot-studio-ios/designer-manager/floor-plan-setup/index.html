Floor Plan Setup

Upload and configure floor plans for device installation

For Designers & Managers

Roles: Designer, Manager

Upload and configure floor plans for device installation.

Accessing Floor Configuration

  1. Navigate to Sites > Select a site > Select a building > Select a floor
  2. Tap to edit floor settings

Uploading a Floor Plan

  1. In the floor detail view, find the floor plan section
  2. Tap Upload floor plan
  3. Select an image from your photo library
  4. The image is uploaded and displayed

Configuring Floor Plan Coordinates

For accurate device positioning, configure the floor plan dimensions:

  1. Reference points: Set known coordinates on the floor plan
  2. Scale: Define the meters-per-pixel ratio
  3. Global coordinates: Optionally set latitude/longitude for geo-referencing

Floor Plan Requirements

Image Format

  • Supported formats: JPEG, PNG
  • Recommended: PNG for better quality
  • Color: Color or grayscale

Image Resolution

  • Minimum: 800 x 600 pixels
  • Recommended: 2000 x 1500 pixels or higher
  • Maximum: Depends on device memory (typically 4096 x 4096)

File Size

  • Recommended: Under 5 MB for faster loading
  • Maximum: 10 MB
  • Larger files may be slower to load on devices

Floor Plan Best Practices

Image Quality

  • Use high-resolution images for better accuracy
  • Ensure the floor plan is properly oriented (north up if geo-referenced)
  • Include scale markers if available
  • Remove unnecessary details that don’t aid device positioning

Coordinate System

  • Set a consistent origin point (e.g., bottom-left corner)
  • Use metric units (meters)
  • Ensure X increases to the right, Y increases upward
  • Verify scale accuracy by measuring known distances

Geo-referencing

For global map display:

  1. Set at least two reference points with known lat/long coordinates
  2. Use corner points or known landmarks
  3. Verify accuracy by checking device positions on the global map

Updating Floor Plans

To replace a floor plan:

  1. Navigate to the floor
  2. Upload a new floor plan image
  3. Reconfigure coordinates if necessary
  4. Verify device positions are still accurate

Note: Replacing a floor plan may require repositioning devices if the scale or orientation changes.

Removing Floor Plans

To remove a floor plan:

  1. Navigate to the floor
  2. Delete the floor plan image
  3. Device positions will be preserved but not visible on a map

Troubleshooting

Floor Plan Not Displaying

If the floor plan doesn’t appear:

  • Verify the image was uploaded successfully
  • Check the image format is supported
  • Try a smaller file size
  • Ensure good network connectivity during upload

Incorrect Scale

If devices appear in wrong positions:

  • Recalculate the meters-per-pixel ratio
  • Verify reference points are accurate
  • Check that coordinate system matches physical reality

Blurry Image

If the floor plan is blurry:

  • Upload a higher resolution image
  • Ensure the original image is clear
  • Avoid excessive compression
